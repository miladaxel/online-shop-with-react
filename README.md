# 🛍️ پلتفرم فروشگاه اینترنتی دیجی‌کالا (Digikala React Front-End Clone)

> **طراحی و پیاده‌سازی کامل رابط کاربری فروشگاه دیجی‌کالا با React 18، تایپ‌اسکریپت (TypeScript)، Tailwind CSS و دیتای جامع Mock.**  
> *کاملاً مستقل از بک‌اند سروری، بدون نیاز به پایگاه‌داده و آماده استقرار مستقیم روی **GitHub Pages**.*

---

## 🌟 ویژگی‌های پیاده‌سازی‌شده در فرانت‌اند

### ۱. 🏪 فروشگاه و تجربه کاربری (E-Commerce UX)
- **رابط کاربری اختصاصی دیجی‌کالا:** طراحی مدرن و کاملاً واکنش‌گرا (RTL) با تایپوگرافی فارسی وزیرمتن (Vazirmatn) و رنگ‌بندی استاندارد دیجی‌کالا (`#ef394e`).
- **پیشنهادهای شگفت‌انگیز (Incredible Offers):** اسلایدر کادربندی‌شده قرمز همراه با شمارنده معکوس، بج‌های درصد تخفیف و نوار وضعیت موجودی.
- **جستجوی زنده لحظه‌ای (Live Search):** جستجوی بلادرنگ در عنوان فارسی/انگلیسی، برند و دسته‌بندی با پیش‌نمایش تصویر، قیمت، تخفیف و هدایت سریع.
- **موتور مقایسه تخصصی کالاها (Comparison Matrix):** مقایسه ستونی ۲ تا ۴ محصول در کنار یکدیگر با استخراج خودکار مشخصات فنی (CPU, RAM, Display, Camera) و دکمه افزودن مستقیم به سبد.
- **لیست علاقه‌مندی‌ها (Wishlist):** نشانه‌گذاری محصولات مورد علاقه برای خرید بعدی با مدیریت در حافظه پایدار کلاینت.
- **سیستم اعلان «موجود شد خبرم کن» (Stock Alert):** ثبت درخواست پیامکی برای شارژ مجدد کالاهای ناموجود (همانند کنسول PS5 Slim در داده‌های دمو).
- **سامانه پیگیری آنلاین مرسوله (Order Tracking):** تایم‌لاین بصری ۵ مرحله‌ای پیشرفت مرسوله همراه با **دکمه تست ارتقای مرحله سفارش (شبیه‌سازی تست)** برای بررسی بصری کارفرما و ارزیاب‌ها.

### ۲. 🏬 مرکز فروشندگان دیجی‌کالا (Seller Center)
- **داشبورد فروشندگان:** کارت‌های شاخص‌های کلیدی عملکرد (KPIs)، ارزش موجودی انبار، هشدار کالاهای ناموجود و رضایت خریداران.
- **مدیریت قیمت و موجودی انبار (Inventory Manager):** جدول تنوع‌ها با قابلیت ویرایش آنی قیمت، درصد تخفیف و تعداد در انبار.
- **افزودن تنوع جدید:** فرم ایجاد تنوع رنگ، گارانتی و قیمت‌گذاری برای کالاهای موجود در کاتالوگ.
- **معماری چندفروشندگی در صفحه کالا:** امکان انتخاب فروشنده رسمی دیجی‌کالا، تکنو پلاس یا دیجیتال استور با قیمت‌ها و گارانتی‌های مجزا برای یک محصول.

### ۳. 🛒 سبد خرید، کدهای تخفیف و تراکنش اتمیک
- **سبد خرید هیبریدی:** ذخیره و همگام‌سازی لحظه‌ای اقلام سبد، تغییر تعداد و استعلام موجودی انبار.
- **موتور کدهای تخفیف (Coupon Engine):** اعتبارسنجی زنده کدهای تخفیف درصدی و مبلغ ثابت با پیام‌های راهنما:
  - `WELCOME`: **۱۰۰,۰۰۰ تومان** تخفیف برای سفارش‌های بالای ۵۰۰,۰۰۰ تومان
  - `DIGI10`: **۱۰٪ تخفیف** تا سقف ۵۰۰,۰۰۰ تومان برای سفارش‌های بالای ۱,۰۰۰,۰۰۰ تومان
- **محاسبه هزینه ارسال:** ارسال رایگان برای خریدهای بالای ۵۰۰,۰۰۰ تومان، در غیر این‌صورت ۴۹,۰۰۰ تومان.
- **فریز نشانی و اقلام (Atomic Snapshot):** ثبت نسخه فریز‌شده مشخصات خریدار و قیمت اقلام در لحظه پرداخت.
- **درگاه پرداخت بانکی شاپرک (Simulated Gateway):** شبیه‌ساز امن درگاه اینترنتی شتاب با شمارنده رمز پویا (OTP)، کد امنیتی، انصراف یا پرداخت موفق، کسر خودکار موجودی انبار، تولید کد رهگیری `REF-xxxxxx` و انیمیشن جشن کانفتی.

### ۴. 👤 احراز هویت پیامکی بدون رمزعبور (Passwordless OTP)
- فرم ورود و ثبت‌نام با شماره موبایل ایرانی (Regex ۱۱ رقمی).
- کد ورود آزمایشی: `۱۲۳۴۵` با قابلیت درج خودکار.
- سوئیچ سریع بین حساب‌ها: **سارا احمدی (مشتری نمونه)** و **مدیر ارشد سیستم (Superuser)**.
- دکمه **«بازنشانی دیتای اولیه»** در هدر برای بازگرداندن کلیه محصولات، انبار، سفارشات و نظرات به حالت اولیه کارخانه.

## 🛠️ فناوری‌های مورد استفاده
- **React 18** (Functional Components + Hooks)
- **TypeScript** (Strict Type Definitions)
- **Vite 5** (Fast Bundling & Build)
- **Tailwind CSS 3** (Custom Digikala Color Palette & Persian Typography)
- **React Router 6 (`HashRouter`)** (تضمین اجرای بدون خطای ۴۰۴ در GitHub Pages و هاست‌های استاتیک)
- **Lucide React** (مجموعه آیکون‌های مدرن)
- **Canvas Confetti** (انیمیشن جشن موفقیت خرید)
- **LocalStorage Storage Manager** (پایداری دیتای موک و تراکنش‌ها)

## 🚀 راهنمای نصب و اجرای لوکال

### ۱. نصب پیش‌نیازها
```bash
npm install
```

### ۲. اجرای سرور توسعه محلی
```bash
npm run dev
```
سپس آدرس `http://localhost:5173/` را در مرورگر باز کنید.

### ۳. ساخت نسخه نهایی پروداکشن
```bash
npm run build
```

## 🌐 نحوه استقرار روی GitHub Pages (Deploy to GitHub Pages)

این ریپازیتوری برای انتشار بر روی گیت‌هاب پیجز کاملاً تنظیم شده است:

```bash
npm run deploy
```
این فرمان به صورت خودکار پروژه را بیلد کرده و محتویات پوشه `dist` را بر روی برنچ `gh-pages` ریپازیتوری شما پوش (Push) می‌کند.
